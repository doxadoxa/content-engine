# Фаза 5 — Пайплайн Generation и GEO-слой

**Покрывает:** Phase 0 спеки, §4 (пайплайн 3), §1 (дифференциация 1).
**Зависит от:** фазы 4.

## Цель

Ежедневный пайплайн, превращающий юнит из плана в готовый draft. Это место, где
живёт главная дифференциация продукта — GEO-слой; без него движок неотличим от
дешёвого генератора.

## Скоуп

Шаги: `outline → draft → фактчек → schema + GEO → draft/автопаблиш`.

### 5.1 Outline и draft

- Промпт собирается из активной версии Brief (фаза 2) + типа юнита + целевого
  запроса.
- Оригинальные данные бизнеса, помеченные планировщиком, вставляются как явный
  вход шага — не «модель придумает».
- Мультилокальность: локали — отдельные юниты одной группы, а не перевод постфактум.

### 5.2 Фактчек

- Отдельный шаг с собственной моделью (§9: дорогая модель на outline/фактчек).
- Для YMYL-проектов (cryptoroute) шаг обязателен и блокирует переход в `draft`
  при непройденных проверках — это требование §1, а не настройка.
- Author schema с реальными именами — обязательное поле для YMYL-проекта.

### 5.3 GEO-слой

- FAQ и HowTo schema, `json_ld` + `faq_json_ld`;
- quotable blocks — самодостаточные абзацы под цитирование в AI-ответах;
- entity coverage — покрытие сущностей темы, проверяемое, а не декларативное;
- совместимость с `llms.txt`.

### 5.4 Режим публикации

- По умолчанию — approve-режим (§1: автопаблиш — привилегия, которую пайплайн
  зарабатывает на конкретном проекте).
- Автопаблиш — флаг проекта, а не глобальная настройка.

## Вне скоупа

Внутренняя перелинковка на pgvector и генерация изображений — фаза 8 (§8 спеки
относит «пайплайн изображений полноценно» и «перелинковку на pgvector» к
Phase 1). Здесь для изображений остаётся только якорь размещения в тексте.

## Критерий выхода

1. Юнит из плана проходит пайплайн целиком и попадает в `draft` с заполненными
   `json_ld`, `faq_json_ld`, quotable-блоками и покрытием сущностей.
2. Юнит YMYL-проекта не может стать `draft` с непройденным фактчеком — по тесту.
3. Известна себестоимость статьи по шагам (критерий выхода Phase 0 спеки).
4. Набор тестов проходит без обращений к провайдерам.
