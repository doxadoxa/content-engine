# Фаза 9 — Петля обратной связи и интеллект

**Покрывает:** Phase 2 спеки (§8), §1 (дифференциация 2, 4), §4 (пайплайн 6).
**Зависит от:** фазы 8.

## Цель

Замкнуть петлю: движок смотрит на результат и меняет своё поведение. Это второе
место дифференциации (§1.2) — «дешёвые генераторы пишут в пустоту».

## Скоуп

### 9.1 Feedback loop

- GSC через официальный API (§9).
- Матчинг по `public_url`, который приёмник вернул ещё в фазе 6.
- Метрики по юниту: индексация, показы, клики, позиции.
- Сигналы в Planning: что сработало — планировать больше, что нет — меньше.

### 9.2 Refresh

- Обнаружение деградации по тренду метрик.
- Refresh-пайплайн: обновление юнита и событие `content.updated` (фаза 6).

### 9.3 Мониторинг AI-цитируемости

Проверка попадания бренда в ответы ChatGPT / Perplexity по целевым запросам.
Метрика, ради которой строился GEO-слой; до этой фазы он оптимизировался вслепую.

### 9.4 Онбординг-агент

Чат, собирающий вводные и компилирующий Brief. Делается последним осознанно
(§3.1): к этому моменту есть четыре отработанных Brief'а как few-shot.

### 9.5 Pull API

Для SSG-сайтов, которым webhook не подходит (§5).

### 9.6 Экран feedback

Индексация, показы, деградация, AI-цитируемость, refresh-очередь (§7).

## Критерий выхода

**Критерий выхода Phase 2 спеки:**

1. План следующего месяца формируется с учётом фактических данных.
2. Минимум одна статья прошла цикл refresh по сигналу деградации.

Дополнительно:

3. Онбординг-агент собирает Brief нового проекта в чате, результат сравним по
   качеству с заполненными руками.
4. Pull API отдаёт корпус проекта с пагинацией и версионированием.
