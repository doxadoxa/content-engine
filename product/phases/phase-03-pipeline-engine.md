# Фаза 3 — Движок пайплайнов и метеринг

**Покрывает:** Phase 0 спеки, §3.3, §4 (инфраструктура), §6.
**Зависит от:** фазы 2.

## Цель

Один механизм исполнения для всех шести пайплайнов §4: DAG шагов-агентов,
состояние в БД, ретрай на уровне шага, учёт токенов и стоимости с первого
запуска. Пайплайны фаз 4–5 после этого — только описания шагов.

## Скоуп

### 3.1 Контракт шага

- Шаг — класс с явными входом и выходом (типизированные DTO), без знания о том,
  кто его вызвал.
- Шаг идемпотентен по `(pipeline_run_id, step_key)`: повтор не создаёт вторую
  сущность.
- Ошибки шага делятся на retryable (сеть, троттлинг, таймаут) и terminal
  (валидация, отказ модели) — от этого зависит, ретраится он или падает.

### 3.2 Runner

- DAG: зависимости между шагами объявлены, порядок вычисляется, независимые
  ветки идут параллельно.
- Состояние в БД, не в памяти воркера: рестарт контейнера не теряет запуск.
- Ретрай с backoff на шаг, ограничение попыток, перевод запуска в `failed` с
  сохранением, на каком шаге и почему.
- Очереди Horizon: раздельные очереди для дешёвых и дорогих шагов, чтобы одна
  долгая генерация не забивала весь пул.

### 3.3 Laragent

Агентные шаги через Laragent (§9). Провайдер и модель — из конфига, не из кода
шага (§9: выбор моделей per-шаг решается по данным метеринга, значит должен
меняться конфигом без правки шагов).

Все обращения к моделям идут через один порт с фейком: набор тестов в сеть не
ходит ни в одной фазе.

### 3.4 Метеринг

`PipelineRun` + `PipelineStep`: модель, входные/выходные токены, стоимость,
латентность, попытки. Прайс-лист моделей — конфиг с версией: пересчёт задним
числом не должен молча менять историю.

Агрегаты: себестоимость юнита, разбивка по шагам, тренд по проекту.

## Вне скоупа

Конкретные пайплайны (фазы 4–5), экраны метеринга (фаза 7 — здесь только данные
и консольная команда).

## Критерий выхода

1. Демонстрационный DAG из четырёх шагов (два параллельных) выполняется в
   очереди и записывает полный след.
2. Убитый посреди запуска воркер: после перезапуска запуск доходит до конца, ни
   один шаг не выполнен дважды — по тесту.
3. Retryable-ошибка на шаге ретраится с backoff, terminal — валит запуск сразу.
4. `php artisan pipeline:cost <project>` печатает себестоимость по шагам.
