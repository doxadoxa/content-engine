# Фаза 7 — Дэшборд оператора

**Покрывает:** Phase 0 спеки, §7 (без экрана feedback).
**Зависит от:** фаз 5 и 6.

## Цель

Закрыть Phase 0 спеки: собрать всё сделанное в рабочий день оператора. Критерий
выхода Phase 0 — «2 проекта публикуют ежедневно без участия оператора, кроме
аппрува» — достижим только когда аппрув занимает минуты, а не выяснение по БД.

Оболочка дэшборда (сайдбар, переключатель проектов, аутентификация, дизайн-
система) сделана в фазе 1; здесь появляется её содержимое.

## Скоуп

- **Календарь контента** (референс — скрин BLG): месяц, карточки со статусами
  (`published / draft / generating / queued`), тип контента, difficulty/volume,
  навигация по месяцам.
- **Карточка юнита:** превью, локали, дерево производных, история версий, аппрув
  и реджект с комментарием. Реджект с комментарием — вход для будущей петли
  качества, поэтому комментарий структурирован, а не свободный текст в логе.
- **Каналы:** мастер подключения (URL → secret → test-доставка `ping`), лог
  доставок, replay, тумблер auto-publish per-channel.
- **Аппрувы:** очередь драфтов на сегодня — главный ежедневный экран.
- **Метеринг:** себестоимость по проектам и шагам, тренд.

## Вне скоупа

Экран feedback (индексация, показы, деградация, AI-цитируемость) — фаза 9.

## Критерий выхода

1. Оператор проходит день целиком из панели: очередь аппрувов → карточка →
   аппрув → публикация видна в логе доставок.
2. Новый канал подключается мастером и проходит test-доставку без консоли.
3. Провалившаяся доставка реплеится из UI.
4. **Критерий выхода Phase 0 спеки:** два проекта публикуют ежедневно, участие
   оператора — только аппрув; себестоимость статьи известна и видна на экране.
